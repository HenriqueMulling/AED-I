# 61. Rotate List

Dada headuma lista ligada, gire a lista para a direita por kposições.

Exemplo 1:

Entrada: head = [1,2,3,4,5], k = 2
 Saída: [4,5,1,2,3]

Exemplo 2:
Entrada: head = [0,1,2], k = 4
 Saída: [2,0,1]
 
Restrições:

O número de nós na lista está no intervalo de [0, 500].
-100 <= Node.val <= 100
0 <= k <= 2 * 109
